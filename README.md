# Cantaloupe Resources

Cantaloupe 프로젝트의 공통 문서와 설계 자료를 관리하는 저장소입니다.

## 범위

이 저장소는 애플리케이션·인프라 구현 코드와 분리해, 프로젝트 전반에서 참조하는 문서를 보관합니다.

- 아키텍처 및 시스템 구성도
- 인프라·Kubernetes 운영 가이드
- 서비스 간 인터페이스와 데이터 계약
- 보안, 비용, 운영 정책
- 개발·배포·장애 대응 절차

구현 코드는 다음 저장소에서 관리합니다.

| 저장소 | 역할 |
| --- | --- |
| `01-infra-provisioning` | 인프라 프로비저닝과 구성 관리 |
| `02-k8s-manifests` | Kubernetes 배포 매니페스트와 플랫폼 정책 |
| `03-app-audio` | 오디오 처리 애플리케이션 |

## 디렉터리 구조

```text
blueprint/
└── 프로젝트의 구조와 원칙을 설명하는 설계 문서
```

문서가 늘어나면 주제별 최상위 디렉터리를 추가합니다. 예를 들어 `architecture/`, `operations/`, `security/`, `runbooks/`를 사용할 수 있습니다.

## 문서 작성 원칙

- 구현 세부사항보다 의도, 제약, 결정의 근거를 우선 기록합니다.
- 코드·매니페스트 저장소의 경로와 변경 가능한 값은 문서에서 명확히 구분합니다.
- 비밀번호, 토큰, 인증서, 내부 접근 정보는 커밋하지 않습니다.
- 운영 절차는 재현 가능한 단계와 검증 방법을 포함합니다.
- 장기적으로 유지해야 하는 결정은 변경일과 영향 범위를 기록합니다.

## 시작하기

1. 문서의 주제와 독자를 정합니다.
2. 관련 구현 저장소와 참조 경로를 문서에 명시합니다.
3. 변경이 필요한 코드·매니페스트가 있으면 해당 저장소에서 별도 변경합니다.
4. 문서 검토 시 정확성, 최신성, 민감정보 포함 여부를 확인합니다.

## 기여

문서 변경은 짧고 검토하기 쉬운 단위로 작성합니다. 새 문서를 추가할 때는 파일명에 주제를 드러내고, 기존 문서의 구조와 용어를 따릅니다.
